# M1 handoff: SDK and live waterfall

**Goal (PRD):** a support-agent run appears as a live waterfall within 2 seconds, with cost per call
(must-have moment 1). Deliverables: Python SDK for Anthropic and OpenAI, ingest pipeline with a bounded
queue and batch writer, live Traces list and trace detail, the demo support agent.

**Status of this plan:** drafted at the end of M0 (2026-09-25). It has **not** had the user's "go" yet.
Step 0 must be answered before building.

## How to use this document (any agent, any step)
1. Read `CLAUDE.md`, then `docs/STATUS.md`. The **M1 step log** there says which steps are done and who is on what.
2. Pick the first step whose `Depends on` steps are all ✅ and that nobody else has claimed. Mark it 🟡 in the step log.
3. Read the step's **Read first** list. Do not rely on memory of earlier sessions; everything you need is in
   the repo, this document and STATUS.md.
4. Build only inside the step's **Owns** paths. Anything outside them goes back to the lead or the user
   (write it under the step's handoff notes in STATUS.md).
5. The step is done when every **Acceptance** check passes. Then mark it ✅ in the step log and fill in the
   **Handoff** notes listed for that step, so the next agent needs nothing from you.
6. If you stop mid-step, mark it ⏸ and write exactly what's done, what isn't, and how to continue.

come before step 2, because step 2's contract builds on them.

## Step 3: Ingest pipeline (backend agent)
**Owns:** `server/` except the contract files. **Depends on:** 2.
**Read first:** PRD "High-volume ingestion", `store.py`, `app.py` lifespan, step 2 contract notes.

- `prism_server/ingest/queue.py`: a `SpanQueue` protocol (`offer(spans) -> bool`, `drain(max_n, timeout)`,
  `depth`, `capacity`) and `InProcessSpanQueue` (bounded by **span count**, env
  `PRISM_INGEST_QUEUE_MAX`, default 50 000). The protocol is the seam where Redis or Kafka slots in later.
- `POST /v1/spans`: validate, `offer` without awaiting the DB, 202 immediately; queue full → 429 +
  `Retry-After: 1`. Never partially accept a batch.
- `prism_server/ingest/writer.py`: a background task started in the lifespan: drain up to 1 000 spans or
  100 ms, whichever first, → `SpanStore.insert_spans`. On DB errors: retry with backoff, then count and
  drop; never crash the app. On shutdown: stop accepting, drain the queue with a timeout.
- Counters behind `GET /v1/ingest/stats`. Live endpoints per D3.
- Previews (D9): migration `0002` adds `input_preview` / `output_preview` to `traces`. Fold rule: take
  them from the root span's `prism.input.preview` / `prism.output.preview`; until the root arrives,
  input = earliest llm span's input preview, output = latest llm span's output preview. Server-side cap
  at `PREVIEW_MAX_CHARS` as a guard even though the SDK truncates.
- Sort (D10): `order=asc|desc` on `(start_time, trace_id)`; the existing index serves both directions
  (check with `EXPLAIN`). Keyset pagination must stay correct in both orders.

**Acceptance (tests, real Postgres):** accepted spans are readable via the query API within 500 ms;
429 when a tiny queue is full, and nothing is lost of what was accepted; previews fold correctly
(root first, root last, no root); paging in both orders returns every trace exactly once; cursor/order
mismatch → 422; writer batches (many small
POSTs → few inserts); duplicate batches don't double-count; shutdown drains; DB outage → errors counted,
app alive. `make check` green.
**Handoff:** env vars, measured drain latency, anything the SDK must know (e.g. Retry-After semantics).

## Step 4: SDK (sdk agent)
**Owns:** `sdk/`. **Depends on:** 2. **Read first:** PRD "SDK mode", `schema.py` (the span shape the
SDK must emit), D4–D6, the stub from step 2.

- Wrapping (D5 API): `anthropic.Anthropic` / `AsyncAnthropic`: `messages.create` (plain, `stream=True`)
  and `messages.stream(...)`; `openai.OpenAI` / `AsyncOpenAI`: `chat.completions.create` (plain,
  `stream=True`). Tool use: tool-call blocks are recorded on the llm span; tool execution is a `@span`.
  One `kind="llm"` span per call with `gen_ai.*` attributes (system, operation, request/response model,
  input/output tokens, finish reasons), `prism.streaming`, `prism.client="sdk"`, previews per D6.
- Previews (D6/D9): llm span input = the last user message's text (tool results summarised as
  `[tool_result lookup_order]`), output = response text plus tool calls as `[tool_use issue_refund]`.
  Root span: input = the first llm call's user message, output = the last llm call's text, unless the
  caller passes `trace(name, input=..., output=...)` explicitly. Truncate at `PREVIEW_MAX_CHARS` and set
  the `*.truncated` flag. For streams, build the output preview from the chunks without holding the
  full response beyond the cap.
  **Do not compute cost in the SDK**; the server prices tokens (single price table).
- Streams: wrap the iterator; pass every chunk to the caller unchanged and as it arrives; record usage
  when the stream ends (or errors / is closed early). D4 for OpenAI.
- `trace()` creates the root `kind="agent"` span; `@span` creates child spans. Parenting goes through
  `contextvars` (works across `await` and threads started with `contextvars.copy_context`).
  IDs: `secrets.token_hex(16)` / `token_hex(8)`.
- Exporter: a daemon thread with a bounded deque (**drop oldest**, count drops); flush every 250 ms or 100
  spans; `POST /v1/spans` with httpx and a short timeout; on 429/5xx/network error back off and keep the
  spans (still bounded); `atexit` flush with a timeout. **Must never raise into, block, or slow the host
  agent.** Never read, log or export request headers or API keys.
- Spans are exported when they **end**, so a live waterfall fills in step by step and the root appears
  last (the dashboard already handles orphans).

**Acceptance:** tests use `httpx.MockTransport` for both the provider clients (hand-written JSON/SSE
bodies; no network, no keys) and the ingest endpoint. They cover sync, async and streaming for both
providers, tool use, nested `@span`, exporter drop-oldest under a full buffer, 429 backoff, ingest down
→ host unaffected, streamed chunks byte-identical to unwrapped, previews truncated with the flag set,
`capture_content=False` emits no preview attributes. A **contract test** validates every
exported span with `prism_server.schema.Span`. `make check` green.
**Handoff:** final public API, config env vars (e.g. `PRISM_ENDPOINT`, `PRISM_DISABLED`), known gaps.
